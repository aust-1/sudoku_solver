# Story 5.3: constraint-workflow

## Status
Draft

## Story
**As a** power user,
**I want** hotkeys and efficient placement workflows for constraints,
**so that** I can configure puzzles quickly.

## Context
This story improves the constraint editing workflow with hotkeys and placement helpers.

## Dependencies
- Story 5.2 should be completed to ensure constraint rendering is in place.

## Acceptance Criteria
1. Hotkeys speed common actions without conflicting with browser defaults.
2. Drag/drop or overlay placement is reliable and repeatable.
3. Power-user flow reduces clicks for frequent edits.

## Tasks / Subtasks
- [ ] Define hotkey map for common constraint actions (AC: 1)
- [ ] Implement hotkey handling without breaking browser defaults (AC: 1)
- [ ] Implement reliable drag/drop or overlay placement workflow (AC: 2)
- [ ] Add UI tests for hotkeys and placement workflows (AC: 1, 2, 3) [Source: docs/architecture.md#Tech Stack]
