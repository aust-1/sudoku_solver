# Story 3.1: solver-interface

## Status
Draft

## Story
**As a** developer,
**I want** a common solver interface with guide, step, and full modes,
**so that** the UI can switch help modes consistently.

## Context
This story defines the solver interface and core mode implementations.

## Dependencies
- None.

## Acceptance Criteria
1. All three modes share a common interface and are swappable at runtime.
2. Each mode returns a consistent result shape (message + delta or full solution).
3. Mode selection does not require UI reload.

## Tasks / Subtasks
- [ ] Define a base Solver interface/class with mode-specific implementations (AC: 1, 2) [Source: docs/architecture.md#High Level Architecture]
  - [ ] Ensure each mode returns a consistent output shape (AC: 2) [Source: docs/architecture.md#StateDelta]
- [ ] Expose runtime selection for helpMode in AppState (AC: 1, 3) [Source: docs/architecture.md#AppState]
- [ ] Add unit tests for solver mode selection and output shapes (AC: 1, 2, 3) [Source: docs/architecture.md#Tech Stack]
