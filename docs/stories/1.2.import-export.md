# Story 1.2: import-export

## Status
Draft

## Story
**As a** user,
**I want** to import and export sudoku boards in a consistent JSON format,
**so that** I can save and reload puzzles without losing data.

## Context
This story implements the core import/export endpoints needed for loading and saving puzzles.

## Dependencies
- Story 1.1 must be completed to finalize schema and validation.

## Acceptance Criteria
1. `GET /api/board` returns JSON strictly compatible with `board.example.json`.
2. `POST /api/board/import` replaces current state and returns a coherent state delta.
3. Import/export round-trip preserves grid, candidates, notes, and constraints.

## Tasks / Subtasks
- [ ] Implement `GET /api/board` to export the current BoardFile (AC: 1, 3) [Source: docs/architecture.md#API Specification]
  - [ ] Map AppState to BoardFile format (AC: 1, 3) [Source: docs/architecture.md#AppState]
- [ ] Implement `POST /api/board/import` to replace current state (AC: 2, 3) [Source: docs/architecture.md#API Specification]
  - [ ] Convert BoardFile to AppState and mark `dirty` appropriately (AC: 2, 3) [Source: docs/architecture.md#AppState]
  - [ ] Return a minimal StateDelta or full state on import (AC: 2) [Source: docs/architecture.md#StateDelta]
- [ ] Ensure constraints are preserved on export and import (AC: 3) [Source: docs/architecture.md#Constraint]
- [ ] Add API tests for import/export round-trip and delta behavior (AC: 1, 2, 3) [Source: docs/architecture.md#Tech Stack]
