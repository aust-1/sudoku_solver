# Story 6.1: one-command-launch

## Status
Draft

## Story
**As a** user,
**I want** a single command to start frontend and backend,
**so that** local setup is frictionless.

## Context
This story creates a one-command local launch workflow.

## Dependencies
- None.

## Acceptance Criteria
1. Single command starts both services on a clean machine.
2. Clear errors are shown if dependencies are missing.
3. Services can be stopped cleanly.

## Tasks / Subtasks
- [ ] Define one-command launch entry point (AC: 1) [Source: docs/architecture.md#Repository Structure]
- [ ] Start frontend and backend processes together (AC: 1) [Source: docs/architecture.md#Tech Stack]
- [ ] Add dependency checks and clear error messaging (AC: 2)
- [ ] Ensure clean shutdown behavior (AC: 3)
- [ ] Add basic documentation for the command (AC: 1, 2, 3)
