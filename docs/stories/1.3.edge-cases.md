# Story 1.3: edge-cases

## Status
Draft

## Story
**As a** user,
**I want** imports to handle edge cases safely,
**so that** unusual boards do not break the solver or UI.

## Context
This story hardens import/export behavior to keep state safe under edge inputs.

## Dependencies
- Story 1.2 must be completed to ensure import/export endpoints exist.

## Acceptance Criteria
1. Empty grid imports without errors and exports correctly.
2. Unknown constraint types are either ignored with warnings or rejected consistently.
3. Partial candidates do not crash the solver or UI; state remains coherent.

## Tasks / Subtasks
- [ ] Define expected behavior for empty grids and partial candidates during import (AC: 1, 3) [Source: docs/architecture.md#Data Models]
  - [ ] Ensure AppState defaults for grid/candidates/notes are coherent (AC: 1, 3) [Source: docs/architecture.md#AppState]
- [ ] Implement consistent handling for unknown constraint types (AC: 2) [Source: docs/architecture.md#Constraint]
  - [ ] Decide and document whether to reject or warn while keeping state stable (AC: 2) [Source: docs/architecture.md#Constraint]
- [ ] Add validation/tests for edge case imports and exports (AC: 1, 2, 3) [Source: docs/architecture.md#Tech Stack]
  - [ ] Verify StateDelta remains valid for all edge cases (AC: 1, 3) [Source: docs/architecture.md#StateDelta]
