# Story 4.3: grid-feedback

## Status
Draft

## Story
**As a** user,
**I want** error highlighting and optional auto-candidates,
**so that** I can spot conflicts and speed up solving.

## Context
This story adds feedback overlays and optional auto-candidate logic in the UI.

## Dependencies
- Story 4.2 should be completed to establish candidates and notes UI.

## Acceptance Criteria
1. Conflicts and invalid states are visibly highlighted.
2. Auto-candidates can be enabled/disabled without losing manual edits.
3. UI remains responsive (< 200 ms) during edits.

## Tasks / Subtasks
- [ ] Implement error/conflict highlighting on the grid (AC: 1)
- [ ] Add auto-candidates toggle and behavior (AC: 2)
- [ ] Ensure auto-candidates do not overwrite manual entries (AC: 2)
- [ ] Add UI tests for highlights and auto-candidates behavior (AC: 1, 2, 3) [Source: docs/architecture.md#Tech Stack]
