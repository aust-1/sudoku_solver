# Story 4.2: candidates-notes-ui

## Status
Draft

## Story
**As a** user,
**I want** to enter candidates and notes per cell,
**so that** I can track pencil marks and reasoning.

## Context
This story adds candidate and notes UI layers on top of the grid.

## Dependencies
- Story 4.1 should be completed to establish the base grid editor.

## Acceptance Criteria
1. Users can toggle candidate mode and enter multiple candidates per cell.
2. Notes are editable per cell and persist across reloads (via API).
3. Candidates/notes are rendered distinctly from final values.

## Tasks / Subtasks
- [ ] Implement candidate mode UI and per-cell candidate entry (AC: 1, 3)
- [ ] Implement notes UI and editing per cell (AC: 2, 3)
- [ ] Wire candidates/notes to `POST /api/candidates/set` and `POST /api/notes/set` (AC: 2) [Source: docs/architecture.md#API Specification]
- [ ] Add UI tests for candidate/notes entry and rendering (AC: 1, 2, 3) [Source: docs/architecture.md#Tech Stack]
