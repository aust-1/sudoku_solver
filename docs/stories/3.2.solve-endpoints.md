# Story 3.2: solve-endpoints

## Status
Draft

## Story
**As a** user,
**I want** to request help via guide/step/full endpoints,
**so that** I can solve puzzles with the desired level of assistance.

## Context
This story implements the API endpoints for solver help modes.

## Dependencies
- Story 3.1 should be completed to define solver modes and output shapes.

## Acceptance Criteria
1. Endpoints respond within acceptable time for typical puzzles.
2. `guide` applies ongoing assistance without breaking user edits.
3. `step` applies exactly one deduction and explains it.
4. `full` returns a completed grid and optional explanation.

## Tasks / Subtasks
- [ ] Implement `POST /api/solve/guide` to return help message + delta (AC: 1, 2) [Source: docs/architecture.md#API Specification]
- [ ] Implement `POST /api/solve/step` to apply a single deduction (AC: 1, 3) [Source: docs/architecture.md#API Specification]
- [ ] Implement `POST /api/solve/full` to return full solution (AC: 1, 4) [Source: docs/architecture.md#API Specification]
- [ ] Add API tests for mode behavior and response shapes (AC: 1, 2, 3, 4) [Source: docs/architecture.md#Tech Stack]
