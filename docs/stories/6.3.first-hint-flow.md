# Story 6.3: first-hint-flow

## Status
Draft

## Story
**As a** new user,
**I want** a documented first-hint flow,
**so that** I can reach a hint in under 60 seconds.

## Context
This story documents and verifies the "first hint" experience.

## Dependencies
- Story 6.2 should be completed to finalize documentation structure.

## Acceptance Criteria
1. A new user can load a sample puzzle and request a hint in < 60 s.
2. The flow is documented step-by-step.
3. The measured time is repeatable.

## Tasks / Subtasks
- [ ] Define a sample puzzle for the first-hint flow (AC: 1)
- [ ] Document the end-to-end steps from launch to hint (AC: 2)
- [ ] Verify the flow timing and adjust steps if needed (AC: 1, 3)
- [ ] Add troubleshooting tips if the hint flow exceeds 60 s (AC: 3)
