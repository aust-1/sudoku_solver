# Story 4.1: grid-editor

## Status
Draft

## Story
**As a** user,
**I want** to edit a 9x9 grid with keyboard and mouse,
**so that** I can input and update puzzle values quickly.

## Context
This story builds the core grid editor UI and basic validation.

## Dependencies
- None.

## Acceptance Criteria
1. Users can select cells via mouse and keyboard and enter values 1-9.
2. Invalid inputs are blocked or clearly indicated.
3. Edits sync to backend state via API calls.

## Tasks / Subtasks
- [ ] Build 9x9 grid UI with selectable cells (AC: 1) [Source: docs/architecture.md#High Level Architecture]
  - [ ] Support mouse selection and keyboard navigation (AC: 1)
- [ ] Implement value entry and basic validation feedback (AC: 1, 2)
- [ ] Wire grid edits to `POST /api/grid/set` endpoint (AC: 3) [Source: docs/architecture.md#API Specification]
- [ ] Add UI tests for selection, entry, and validation states (AC: 1, 2, 3) [Source: docs/architecture.md#Tech Stack]
