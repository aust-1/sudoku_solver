# Story 5.2: constraint-rendering

## Status
Draft

## Story
**As a** user,
**I want** constraints to render visually on the grid,
**so that** I can see and verify the puzzle rules.

## Context
This story adds visual rendering of MVP constraints on the grid.

## Dependencies
- Story 5.1 should be completed to ensure constraints are created in UI.

## Acceptance Criteria
1. All MVP constraints render clearly on the grid.
2. Visuals update immediately after edits.
3. Rendering does not degrade grid interaction performance.

## Tasks / Subtasks
- [ ] Implement rendering overlays for MVP constraint types (AC: 1, 2)
- [ ] Update rendering on constraint add/update/remove (AC: 2) [Source: docs/architecture.md#StateDelta]
- [ ] Optimize rendering for performance during grid edits (AC: 3)
- [ ] Add UI tests for constraint visuals and update behavior (AC: 1, 2, 3) [Source: docs/architecture.md#Tech Stack]
