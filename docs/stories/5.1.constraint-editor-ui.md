# Story 5.1: constraint-editor-ui

## Status
Draft

## Story
**As a** user,
**I want** to add, edit, and remove constraints via the UI,
**so that** I can configure puzzle rules visually.

## Context
This story builds the constraint editor UI and connects it to the API.

## Dependencies
- None.

## Acceptance Criteria
1. Users can add a constraint with required parameters via UI.
2. Constraints are editable and deletable without page reload.
3. UI actions map directly to API add/update/remove.

## Tasks / Subtasks
- [ ] Build UI for adding/editing/removing constraints (AC: 1, 2)
- [ ] Wire UI actions to `POST /api/constraints/add|update|remove` (AC: 3) [Source: docs/architecture.md#API Specification]
- [ ] Ensure UI state stays in sync with AppState constraints (AC: 2, 3) [Source: docs/architecture.md#AppState]
- [ ] Add UI tests for constraint CRUD flows (AC: 1, 2, 3) [Source: docs/architecture.md#Tech Stack]
